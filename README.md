# 💻 Задание №2 — LZ77

## 📌 Описание

Реализован алгоритм сжатия **LZ77**, основанный на поиске повторяющихся подстрок.

Алгоритм кодирует строку в последовательность троек:

```
(offset, length, next_char)
```

---

## ⚙️ Возможности

* кодирование текста в формат LZ77
* декодирование из JSON
* работа с произвольным текстом (включая UTF-8)

---

## ▶️ Как запустить

Открыть файл:

```
lz77_site/index.html
```

---

## 🧪 Пример

Вход:

```
abracadabra
```

Выход:

```
[ [0,0,"a"], [0,0,"b"], [0,0,"r"], ... ]
```

---

# 🔐 Задание №3 — DES

## 📌 Описание

Реализован алгоритм симметричного шифрования **DES (Data Encryption Standard)**.

Используется один и тот же ключ для:

* шифрования
* дешифрования

---

## ⚙️ Возможности

* шифрование текста
* дешифрование
* работа с ASCII и UTF-8 строками
* отображение результата в удобном формате

---

## ▶️ Как запустить

Открыть файл:

```
des_site/index.html
```

---

## 🧪 Пример

Текст:

```
Hello DES!
```

Ключ:

```
mykey123
```

Результат:

* шифртекст
* корректное восстановление исходного текста
